# Practice
A practice repository for gaining experience and becoming familiar with GitHub's features.
## Practicing the basics of branching from main repository

# documenting the GitHub Flow for reference
  - Create a branch: a clone repository where changes are made
  - make changes: creating, changing, moving, or deleting files. Commit and push changes to the branch which will save changes in remote storage.
  - Create a pull request: asking collaborators for feedback on changes made.
  - Address review comments:
  - Merge pull request: once request is approved merge pull request, automatically merge branch
  - Delete the branch: after merge your branch can be deleted
